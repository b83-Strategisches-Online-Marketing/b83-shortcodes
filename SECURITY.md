# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils aktuelle Version. Bitte immer die neueste Version aus den [Releases](https://github.com/b83-Strategisches-Online-Marketing/b83-shortcodes/releases) verwenden.

## Sicherheitslücke melden

Bitte **keine öffentlichen Issues** für Sicherheitslücken anlegen.

- Bevorzugt: über GitHub unter *Security → Report a vulnerability* (private Meldung)
- Alternativ: per E-Mail an office@b83.at

Hilfreich sind eine kurze Beschreibung, betroffene Version und Schritte zum Nachstellen. Wir melden uns in der Regel innerhalb von 5 Werktagen und informieren über die Behebung.

---

# Security Policy (English)

Please do not open public issues for security vulnerabilities. Report them privately via *Security → Report a vulnerability* on GitHub or by email to office@b83.at.
