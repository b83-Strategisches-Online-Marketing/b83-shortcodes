Eigene Shortcodes mit HTML, CSS und JavaScript verwalten. Keine PHP-Ausführung.

== Beschreibung ==

Mit b83 Shortcodes legst du eigene Shortcodes an und bindest sie in Elementor, im Block-Editor oder in Widgets ein. Jeder Shortcode hat zwei Code-Felder: eines für die Stelle des Shortcodes und eines für das Seitenende, das pro Seite nur einmal ausgegeben wird.

* Shortcodes mit HTML, CSS und JavaScript, ohne PHP
* Code am Seitenende, auch wenn der Shortcode mehrfach vorkommt
* Platzhalter in der Editor-Vorschau von Elementor und anderen Page Buildern
* Export und Import als JSON
* Leert den Cache betroffener Seiten nach dem Speichern
* Verwalten dürfen nur Benutzer mit den Rechten `manage_options` und `unfiltered_html`

Die Einstellungen liegen im Menü „b83“. Support: office@b83.at

== Installation ==

1. Plugin-ZIP unter Plugins → Installieren → Plugin hochladen einspielen.
2. Plugin aktivieren.
3. Unter b83 → Shortcodes den ersten Shortcode anlegen.
